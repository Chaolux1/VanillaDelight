# Vanilla Delight

Vanilla Delights is an addon for Farmer’s Delight that adds new dishes, drinks, and ingredients made mostly from vanilla Minecraft food. It also adds more freedom when building a kitchen, with customizable Cabinets, Stoves, Cooking Pots, and Cutting Boards.

## 💻 Development
