# Vanilla Delight

## 📜 Essence

This mod expands Farmer’s Delight by adding 30+ new food items — all made using only vanilla Minecraft ingredients. It gives more variety to survival cooking without adding anything outside the base game.

## 🎯 Features

- 30+ new food items crafted fully from vanilla resources.
- Full Farmer’s Delight integration: cutting, cooking, crafting.
- Balanced recipes that feel natural in Minecraft survival.
- Creative use of common ingredients like melon, honey, and berries.
- Meals range from simple snacks to big feasts.
- Clean and simple — no extra mods or new crops needed.
